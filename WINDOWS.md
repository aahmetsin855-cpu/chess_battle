# Windows

Проект не использует Linux-only API. Пути к `data/` строятся относительно каталога проекта (или каталога `.exe` в собранном виде — см. WINDOWS_BUILD.md), поэтому запуск из ярлыка/`.bat`/собранного приложения не ломает сохранения.

## Запуск из исходников

1. Установить Python 3.13 x64.
2. Открыть PowerShell/CMD в каталоге проекта.
3. Выполнить `py -3 -m pip install -r requirements.txt`.
4. Запустить `run_windows.bat` или `py -3 main.py`.

Для LAN Windows Firewall может показать запрос на доступ Python к локальной сети — для игры по LAN нужно разрешить частную сеть.

Музыка и фон выбираются через системный диалог файлов. Путь сохраняется в `data/settings.json` на конкретном компьютере. Для музыки реальные поддерживаемые форматы зависят от SDL_mixer/Pygame; обычно подходят WAV/OGG/MP3.

## Сборка отдельного .exe (PyInstaller)

См. **WINDOWS_BUILD.md** — там пошаговая сборка (`build_windows.bat` + `hp_chess.spec`), чек-лист ручной проверки и отдельные разделы про LAN и обнаружение Ollama именно в собранном виде.
